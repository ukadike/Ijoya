# Prototype Roadmap

Status: tracking document, updated as work lands. Do not skip ahead — the
project directive is explicit that expansion toward the full installation
only happens after Prototype 5.

| # | Scope | Status |
|---|---|---|
| 1 | One body · one sensor · soft movement | Not started |
| 2 | Two bodies · one body triggers another | Not started |
| 3 | Borrowed function (the core concept made physically observable) | Not started |
| 4 | Three-body interaction chain | Not started |
| 5 | Environmental participation (soil moisture, humidity, wind, rainfall, light, temperature, vibration, touch, proximity) | Not started |

## Prototype 1 — One body, sensor, soft movement

- **Goal:** a single sculptural body senses one input and produces one soft
  physical response. No inter-body communication yet.
- **Exit criteria:** the body's behavior can be documented against the
  template in [`behaviors/TEMPLATE.md`](./behaviors/TEMPLATE.md); movement
  reads as organic (breathing/leaning/yielding), not industrial-robotic.

## Prototype 2 — Two bodies, one triggers another

- **Goal:** first real use of the [behavioral language](./behavioral-language.md)
  — one body's sensed event produces a message that changes a second body's
  state.
- **Exit criteria:** the message exchange is documented, and the physical
  response in the second body is visibly caused by the first (interdependence
  is observable without explanation, per the directive).

## Prototype 3 — Borrowed function

- **Goal:** the phrase "borrowed function" becomes physically observable —
  e.g. one body stabilizes another, tension in one changes another's
  posture, air or pressure is shared.
- **Exit criteria:** a visitor unfamiliar with the project can observe the
  dependency without being told about it.

## Prototype 4 — Three-body interaction chain

- **Goal:** propagate a response across three bodies, still without a
  master/coordinator body.

## Prototype 5 — Environmental participation

- **Goal:** the garden itself (soil, humidity, wind, rainfall, light,
  temperature) becomes an input that influences collective behavior.

## After Prototype 5

Expansion toward the complete installation. Not yet scoped — **OPEN
QUESTION** until Prototype 5 is complete.
