# Ìjóyà: Borrowed Function in the Garden

Connections through the joy of dance.

An interactive soft-robotic installation exploring interdependence,
accessibility, communication, collective care, and environmental
reciprocity. Multiple soft sculptural bodies share a garden; no body is
complete by itself, and every body borrows function from another.

> We dance in the garden together because we cannot function alone.

Before contributing, read [`CLAUDE.md`](./CLAUDE.md) — the project
directive governing artistic, accessibility, and architectural decisions —
and see [`docs/`](./docs/) for the behavioral language, state model,
prototype roadmap, accessibility checklist, and architecture decision
records.
