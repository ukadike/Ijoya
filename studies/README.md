# Studies

Working notes, iteration records and test results.

Nothing has been prototyped yet, so this directory is currently a placeholder. As prototyping begins, record each test here — what was tried, what happened, what it changed about the design.

Suggested format, one file per test:

```
studies/YYYY-MM-DD-short-name.md

## What was tested
## What happened
## What it changes
## Photos
```

Record failures. A test that did not work is more useful to future-you than one that did.
